# 에이전트 기획안 — AI 의료기기 규제 동향 브리핑

작성: 박주이 · 강의용 예시 · 버전 v0.1 · 상태: 오전 실습에서 돌린 팀을 기획안으로 거꾸로 적은 것

## 0. 한 줄 요약

담당자가 주제 한 줄을 주면 → 식약처·미국 FDA·EU 자료를 병렬로 조사해 출처가 달린 4쪽 동향 브리핑이 `산출/브리핑_주제_날짜.md`와 한글 문서로 나온다

## 1. 페인포인트 — 지금은 어떻게 하고 있나

- 현재 절차: 관련 기관 사이트 순회 ★ → 새 문서 확인 → 요지 정리 ★ → 출처 링크 정리 ★ → 보고 양식에 옮겨 적기 ★
- 빈도 · 소요: 월 1~2회 · 회당 반나절
- 자주 나는 실수 · 불편: 발행일 착오 · 개정 전 문서 인용 · 출처 링크 누락 · 기관마다 문서 형식이 달라 요지 추출에 시간 소모
- 이 일을 하지 않으면 생기는 일: 회원사 문의에 옛 규정으로 답할 위험

## 2. 목표와 완료 정의

- 목표(한 문장): 주제 한 줄로 최신 규제·표준 동향 브리핑 초안을 출처와 함께 받는다
- 끝났다는 것을 어떻게 아는가: `산출/`에 브리핑 md와 검증 보고서가 생기고, 검증 보고서의 ❌가 0건이며, 본문의 모든 수치·날짜 옆에 출처가 있다
- 하지 않는 것(범위 밖): 회원사에 직접 발송하지 않는다 · 규제 해석(법적 판단)은 하지 않고 원문 요지만 옮긴다

## 5. 처리 단계 — 에이전트가 할 일의 순서

| 단계 | 입력 → 처리 → 출력 | 쓰는 도구 · 자료원 | 사람이 서는 관문 |
|---|---|---|---|
| 1 | 주제 → 연구질문 · 목차 · 조사 계획 → `01_설계.md` | 설계자 | ★ 목차 승인 |
| 2 | 목차 → 식약처 · FDA · EU 병렬 조사 → `02_조사_*.md` | 조사관 3인(웹 검색 · 문서 도구) | — |
| 3 | 조사 파일 → 출처 실재 · 수치 원문 대조 → `02a_검증.md` | 검수관(읽기 전용) | — |
| 4 | 검증 통과분 → 집필 → `03_초안.md` | 집필가 | — |
| 5 | 초안 → 논리 · 출처 · 교열 검수 → 수정 요청 | 검수관 | ★ 최종 확인 |
| 6 | 초안 → 한글 문서 변환 → `산출/브리핑.hwpx` | 변환가(hwpx 도구) | — |

## 6. 검증 항목 — 통과 기준

| 검사 | 방법 | 통과 기준 |
|---|---|---|
| 출처 실재 | 링크 열기 · 문서명 · 발행기관 · 발행일 대조 | 전부 열리고 발행일 일치, 안 열리면 〔색인확인〕으로 낮추고 표시 |
| 수치 · 날짜 원문 대조 | 본문의 숫자를 원문에서 다시 찾기 | 전부 일치, 계산 · 추정 수치는 "추정"이라고 표시 |
| 현행 여부 | 개정판 · 폐지 여부 확인 | 개정 전 문서 인용 0건 |
| 재인용 체인 | 같은 보도자료를 받아쓴 기사끼리 교차검증으로 세지 않기 | 1차 출처 1건 이상 |
| 형식 | 4쪽 · 배경 → 쟁점 → 근거 → 제언 · 각 절 출처 | 항목 누락 0 |

## 7. 금지 사항 · 권한

- 반입 금지 자료: 회원사 비공개 인허가 서류 · 환자 데이터 · 계약서 · 인증키
- 하면 안 되는 행동: 원문 없는 수치 쓰기 · 규제 해석을 단정하기 · 회원사 발송 · `입력/` 밖 파일 수정
- 허용 권한: 읽기: `입력/` · 웹(공개 사이트) / 쓰기: `_workspace/` `산출/`만
- 이 절은 그대로 `CLAUDE.md`의 규칙으로 옮긴다

## 8. 도구 · 자료원

| 필요한 것 | 이름 | 없으면 |
|---|---|---|
| 웹 검색 · 원문 열기 | 기본 웹 도구 | — |
| 한글 문서 읽기 · 쓰기 | hwpx 도구(MCP) | 찾아서 제안 |
| 법령 · 고시 현행 확인 | 국가법령정보 MCP | 찾아서 제안 |
| 출처 검증 | 출처 검증 스킬(fact-verify) | 저장소에서 설치 |
| 교정 | 교정교열 스킬 | 저장소에서 설치 |

## 9. 실행 방식

- 부르는 방법: 수동 — "규제 동향 브리핑 팀으로 ○○ 주제 브리핑 만들어줘" / 확장 시 예약 — 매주 월요일 08:00 신규 문서 감시
- 실패했을 때: 조사관이 원문을 못 열면 〔색인확인〕으로 표기하고 계속, 검수 ❌가 남으면 저장하지 않고 이유 보고
- 결과 보고: 한 줄 요약 + 검증 표 + 산출 파일 경로
