워크플로 패턴: 병렬

관점이 여럿인 일 — 식약처 · FDA · EU 조사관

이럴 때 쓴다

  • 같은 주제를 여러 각도에서 봐야 할 때 식약처 · FDA · EU 문서를 각각
  • 대상이 여럿이고 서로 독립일 때 표준 문서 10종을 각각 대조
  • 여러 관점의 검수가 필요할 때 출처 · 논리 · 표기를 각각

설계 요령

  • 각자에게 겹치지 않는 범위를 준다 — 안 그러면 중복 조사
  • 결과 형식을 똑같이 맞춘다 — 나중에 합쳐야 하니
  • 합치는 단계를 따로 둔다 — 중복 제거와 상충 처리
  • 상충하면 지우지 말고 둘 다 남긴다
병렬의 함정 — 같은 원출처를 다르게 요약하면 합칠 때 서로 다른 사실처럼 보이므로 출처 기록이 필수

  • 팀원이 늘어도 사람의 부담은 그대로다

서로에게서 가져갈 것

공통으로 나오는 것

  • 대부분 같은 지점에서 막힘 — 범위를 너무 크게 잡았을 때
  • 관문은 대개 "수치가 틀리면 안 되는 곳"에 섬
  • 가장 빨리 성공한 것은 가장 단순한 것

돌아가서 서로 할 수 있는 것

  • 만든 스킬 파일을 공유 — 폴더째 복사하면 됨
  • 기관 표기 규칙(문서명 · 기관명 · 단위)은 한 사람이 정리해 같이 씀
  • 막힌 것은 모아서 물어봄 — 개별로 헤매지 말고

한 사람만 아는 절차담당이 바뀌면 사라질 지식스킬로 굳혀 인수인계 자산으로
