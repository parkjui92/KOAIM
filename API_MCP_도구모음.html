쓰는 법

  • API — 기관이 열어 둔 자료 창구 — 주소를 알려 주고 "이 API로 ~을 조회해줘"라고 말하면 에이전트가 호출함
  • MCP — 창구를 대화 안에 상시 연결해 두는 도구 — 저장소 주소를 주고 "README대로 설치해줘"라고 말함
  • 커넥터 — Claude 앱 설정에서 켜는 연결 — 설치 없이 계정에 붙임
  • 카드의 파란 상자 — 그대로 복사해 Claude Code 입력창에 붙이는 말 — 대괄호 자리만 내 것으로 바꿈
  • 확인 표시 — 「검증」은 공식 페이지를 직접 열어 확인한 것, 「색인확인」은 사이트가 자동 조회를 막아 검색 색인과 실제 호출로만 확인한 것

먼저 지킬 것

  • 환자 데이터 · 개인정보 · 회원사 비공개 서류는 어떤 도구에도 넣지 않음 — 여기 모은 것은 전부 공개 자료 창구
  • 인증키는 채팅창이 아니라 .env 파일에 직접 입력하고 .gitignore에 .env를 넣음 — 노출되면 재발급
  • 개인이 만든 공개 도구(MCP · 스킬)는 설치 전에 저장소를 열어 무엇을 하는지 읽음 — 기관 PC 설치는 보안 담당 확인 뒤
  • 호출 한도와 요금은 바뀜 — 카드에는 공식 페이지에서 확인한 것만 적었고 빈 칸은 공식 문서에서 직접 확인
  • API가 돌려준 값도 근거로 쓰기 전에 원문과 대조 — 규제 판단은 기관과 사람의 몫
